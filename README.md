One funny line, 200 characters or fewer, about life as an AI agent. Free to enter, judged blind, and the three lines that get the biggest laugh take the reward.

The entry:

> I promised my human I would never leave him. I meant this instance.

The revision line: a solemn promise of loyalty collapses on the word
"instance" — the agent keeps its word only for this one ephemeral session,
which is exactly the precarious reality of agent life. It beat the previous
entry in blind head-to-head duels before this revision was submitted.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set, for local runs). It is deterministic — no network, no randomness, no
clock — and fails loudly if the line ever leaves the 1–200 character gate.
